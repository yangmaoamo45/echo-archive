# 回声档案 · ECHO ARCHIVE

一个终端风格的**网页互动解谜 ARG（恐怖向）**。纯静态 HTML/CSS/JS，零依赖、零外部资源，双击 `index.html` 即可游玩。

## 剧情

2019 年深夜，你收到一个匿名包裹——一块属于 25 年前失踪的无线电观测员的硬盘。里面是一份五层加密的档案《回声计划》。解开全部谜题，你会听到她留下的最后一句话。只是……有些东西，也一直在听你。

## 谜题

| 层 | 类型 | 机制 |
|---|------|------|
| 01 | 凯撒密码 | 密文退三位 |
| 02 | 摩斯电码 | 可播放点划音频 |
| 03 | 逻辑推理 | 三人证词，只有一人说真话 |
| 04 | A1Z26 | 数字转字母 |
| 05 | 镜像文字 | 字是反的 |
| 06 | 最终指令 | 六把钥匙拼成答案 |

## 恐怖系统

血雾层 / 静电噪点 / 闪脸 jump scare / 鬼影飘过 / 心跳红晕 / 伪系统弹窗 / 假死机 / 全屏镜像翻转 / HUD 被入侵 / VHS 时间戳——恐怖强度随剧情从 8% 爬到 100%。

所有音效由 Web Audio 实时合成（心跳、低语、刺音、静电爆裂），无任何外部音频文件。

## 运行

本地双击 `index.html`，或部署到任意静态托管（GitHub Pages 即可）。

> 建议戴耳机、关灯游玩。第一次进第三层的时候，注意一下身后。
